# Sécurité

- Supabase Auth pour les sessions et mots de passe.
- RLS PostgreSQL pour l’autorisation réelle.
- Edge Functions pour la création de comptes et les certificats.
- Storage privé et URL signée.
- Audit des opérations sensibles.
- Aucun secret ou mot de passe de démonstration dans Git.
- Aucun secret JWT de secours dans le backend hérité.
- Validation SQL et frontend des UUID, montants, dates, notes, fichiers et statuts.
